# KR1 — HTML-страница и базовая стилизация CSS

## Описание проекта

Учебный проект интернет-магазина техники TechStore. Страница создана на HTML5 и CSS3 без сторонних библиотек.

## Структура

```text
kr1-html-css-shop/
├── index.html
├── css/
│   └── style.css
└── README.md
```

## Реализовано

- Семантическая структура страницы: `header`, `nav`, один `main`, `section`, `article`, `aside`, `footer`.
- Главный экран с заголовком и ссылкой-кнопкой.
- Блок преимуществ магазина.
- Три карточки популярных товаров.
- Дополнительный информационный блок и `aside`.
- Подключение внешнего файла CSS.
- Базовый сброс `box-sizing: border-box` и `margin: 0` для `body`.
- Стилизация навигации, секций, карточек, кнопок и подвала.
- Адаптивная сетка для экранов планшетов и телефонов.
- Переходы и эффекты наведения.

## Запуск

Откройте `index.html` в браузере. Дополнительная сборка или установка зависимостей не требуется.

## История изменений

- Добавлен внешний файл `css/style.css`.

- Добавлена адаптация для мобильных экранов.

## Git

Команды для выполнения требований по ветке и отправке изменений:

```bash
git checkout -b feature/html-css-start-page
git add index.html css/style.css README.md
git commit -m "feat: add styled HTML shop landing page"
git push -u origin feature/html-css-start-page
```

После отправки ветки создайте Pull Request из `feature/html-css-start-page` в `main`.
